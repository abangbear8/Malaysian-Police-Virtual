# Polis Malaysia Tycoon — Prototaip 0.1

Prototaip web 3D dari kosong menggunakan Three.js, TypeScript dan Vite.

## Fungsi
- Persekitaran bandar 3D stylized, balai polis, jalan dan NPC ringkas.
- Kawalan watak WASD / anak panah dan kawalan sentuh.
- Interaksi misi berhampiran penanda misi.
- Enam kategori tugasan asas.
- XP, prestasi, reputasi, ganjaran dan kemajuan pangkat prototaip.
- Simpanan setempat dalam pelayar.

## Keperluan dan cara jalankan
Node.js 20+ disyorkan.

```bash
npm install
npm run dev
```
Buka URL Vite yang dipaparkan, biasanya http://localhost:5173.

Untuk semak binaan: `npm run build`.

## Nota
Nilai XP, reputasi dan pangkat ialah parameter permainan sementara, bukan skala rasmi PDRM. Simpanan hanya setempat; tiada akaun atau cloud save. NPC dan tugasan merupakan simulasi permainan.
